# Task: 掌握词随机选择算法（TDD）

## 类型
dev

## 优先级
P1

## 依赖
T1（mastered-pool.js 存储模块）

## 描述
实现掌握词的随机选择逻辑：每天从掌握词池中随机选 3 个未复习过的词。

### 算法需求
1. **输入**：所有 `round >= 7` 或 `mastered === true` 的词列表
2. **过滤**：排除 MasteredPool 中今天已随机到的词
3. **随机选择**：从未复习的掌握词中随机选 3 个
4. **标记**：将选中的 3 个词加入 MasteredPool
5. **轮完重置**：如果未复习的掌握词数量为 0（全部轮完），先重置 MasteredPool，再随机选 3 个

### 修改文件
- `js/mastered-pool.js` 添加 `selectRandom(pool, count)` 方法
- 或直接在 `js/app.js` 中实现

### 验收标准
- 随机选择均匀分布（多次调用覆盖所有词）
- 不重复选择今天已选过的词
- 全部轮完后自动重置
- 掌握词不足 3 个时，选择全部剩余
- 掌握词为空时，返回空数组
