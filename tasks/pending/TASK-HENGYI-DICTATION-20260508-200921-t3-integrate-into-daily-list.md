# Task: 掌握词混入当日听写列表

## 类型
dev

## 优先级
P1

## 依赖
T0（间隔调整），T2（随机选择算法）

## 描述
将随机选中的 3 个掌握词混入当日听写列表。

### 集成点
- `buildTodayList()` 或类似的每日列表构建函数
- 在新词 + 复习词之后，追加 3 个掌握词
- 掌握词标记为 `type: 'mastered'` 以便 UI 区分

### 修改文件
- `js/app.js`：修改每日列表构建逻辑

### 验收标准
- 掌握词出现在当日听写列表中
- 听写总数 = 新词数 + 复习到期数 + 掌握随机数（最多3个）
- 掌握词在听写流程中正常播放、正常判对错
- 听写结果页显示掌握词的正确率（可选）
